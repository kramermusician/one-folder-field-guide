# 12. Glossary

- Vault: the folder, seen through Obsidian.
- Node: one markdown file about one thing (a person, course, topic).
- Wikilink: `[[file-name|Shown Name]]`, a clickable link between files.
- Alias: other names for a node, listed at its top.
- Frontmatter: the block between `---` lines at the top of a file.
- Watcher: a small program that notices new files and acts on them.
- Route prompt: the instructions the AI follows when sorting a memo.
- SOP: a checklist for one kind of job.
- Specialist or teammate: a role file in `team/`.
- Orchestrator: the teammate that routes requests to the others.
- Coaching loop: correction becomes a written rule.
