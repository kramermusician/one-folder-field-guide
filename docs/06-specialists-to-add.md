# 06. Specialists to add next

A menu. Pick two that match real pain this month. Names are suggestions; rename them.

## For teachers
- Lesson planner: turns "week 5, past tense" into a 50-minute plan (open, teach, apply, close).
- Assessment designer: quizzes and rubrics that test one thing at a time, with answer keys.
- Level checker: rewrites any text to a target level (A2, B1, B2) and flags hard words.
- Course logger: after each class, you talk for 60 seconds; it writes what happened and what to change next time.
- Canvas or LMS helper: formats pages and announcements for your learning platform (drafts only).

## For musicians
- Chart maker: lead sheets and setlists from a list of songs and keys.
- Practice coach: builds a weekly practice plan and logs what you did.
- Gig booker: keeps a file per venue and contact (people folder again), drafts follow-ups.

## For life
- Calendar keeper: turns "lunch with Ana Thursday" into a calendar draft.
- Inbox drafter: writes email drafts in your voice. Never sends.
- Plant or garden keeper, health logger, travel planner: whatever you actually care about.

## For the system itself
- Librarian: keeps a catalog of every file so "do we already have this?" has an answer.
- Voice editor: checks anything written as you sounds like you.
- Researcher: finds sources, quotes them, lists links. Never invents a citation.
- Quality gate: the final check before anything leaves your hands.
- Code reviewer: reads any script the AI wrote before you trust it.
- Language tutors: one per language you're learning, each knowing your level.

## How to hire one

1. Copy `team/_new-teammate-TEMPLATE.md` to `team/<name>.md`.
2. Ask the AI: "Interview me to fill this in. Five questions max."
3. Add one routing line to CLAUDE.md.
4. Give it a real job today. Coach it once. Save the rule.
