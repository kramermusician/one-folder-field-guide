# One-Folder Field Guide

A companion to the One-Folder Starter Kit (https://kramermusician.github.io/one-folder-starter-kit/). The kit gets you running. This guide explains how a mature one-folder system works after a year of daily use, so you can grow yours on purpose.

The system it describes is called KRAMOS. Yours will become something else, with its own name. Steal the patterns, not the specifics.

## Works with Claude Code or Codex

Everything here is plain markdown. Claude Code reads `CLAUDE.md`; Codex reads `AGENTS.md`. Keep one as the real file and have the other say "read CLAUDE.md".
